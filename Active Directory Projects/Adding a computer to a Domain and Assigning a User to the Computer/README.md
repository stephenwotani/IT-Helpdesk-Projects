## Adding a computer the a domain and assigning a user to the computer
This is very important in active directory because when a new employee joins a company and the company has to get them a new device or if the employee brings their own device then that computer has to be join the company's domain in active directory to gain access to enterprise resources. aslo it might be a case of replacing an employees failed device to another.   

## steps to add a computer to a domain
-One has to go to the computer settings and change the computer from a work group to a Domain. 
-The domain name has to be entered then a the admin Credentials has to be entered.  
## Assigning a User to a specific Device
This is important to as to know which employee is using which machine for easy management by the IT team.  

This can be done in the Active Directory Tool Users and Computers and going to the specific user and under their properties they will **LOGON** a specific devicethen the name of the device is selected
