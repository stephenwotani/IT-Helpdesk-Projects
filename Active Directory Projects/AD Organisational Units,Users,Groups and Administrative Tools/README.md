4)**Organisational UNITS (OU)** : Organisational units in Active Directory allow IT admins to logically organise objects within a domain    
    
    **  Benefits of OU**:   
    -Better Organisation
    -Easier Administration
    -Better Security
    -Better Scalability
    -Better Policy Control
    -Better Operational Efficiency
