## Creating and Deleting Users in Active Directory  
Creating and Deleting users in active directory is important for on boarding and off boarding when an employee joins the company their account has to be created so they can access company resources  and when an employee is leaving the company their accounts have o be deleted to prevent them from accessing company resources    

This is done using the Users and Computers Tool in Active Directory.
## Basic User Management in Active Directory 
-Reset Passwords
-Disable Account
-Enable Account
-Review Properties
