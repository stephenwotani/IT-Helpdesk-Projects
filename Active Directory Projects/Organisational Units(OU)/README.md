# Organiasational Units In Active Directory  
In Active Directory,Organisational Units helps us to logically organise objects inside a domain.  
eg,    
-Seperate Departments      
-Seperateservers and workstations   
-Delegating Administration   
-Applying Group Policy    

## Benefits of Organisational Units 
-Better Organisation  
-Easier Administration  
-Better Security  
-Better Scalability  
-Better Policy Control  
-Better Operational Efficiency.
