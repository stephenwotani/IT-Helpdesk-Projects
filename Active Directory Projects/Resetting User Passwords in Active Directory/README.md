## Resetting User Passwords In Active Directory
Resetting User Passwords in active directory is a very important concept to know because daily employees forget their passwords because most companies require robust passwords with upper and lower case letters,special characters,numbers etc. which makes remembering all difficult. so as an IT support tickets will be generated daily requesting to get passwords changes.  
This Can be done using the Active Directory Tool **Users and Computers**
